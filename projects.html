Space Race

A desktop arcade game where you steer a spaceship with the left and right arrow keys to dodge falling asteroids.

The score increases as the game runs, and a collision resets it. A high score tracks your best score during the session. A moving star field, background music, and collision sounds complete the game.

Inside the code

The project uses a scheduled game loop, keyboard input, sprites, random asteroid spawning, and distance-based collision detection.

Space Race is a Python desktop game built with Pyglet.
